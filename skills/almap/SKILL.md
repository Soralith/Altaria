## What I do

I generate a clean directory tree of the project, filtering out node_modules, .git, build artifacts, and cache directories.

## When to use me

Use when the user asks to map, tree, or visualize the project structure — or when you need to understand the directory layout.

## Instructions

Call `altaria_map_structure` to generate the tree. Present it clearly and write the full output to `Altaria/Altaria-Map.md` in the project root.
