## What I do

I scan the project directory and provide a comprehensive report covering:
- Tech stack (framework, language, build tools)
- Database (ORM, client)
- Architecture style (MVC, component-based, routes)
- Directory structure (abbreviated tree)
- Core capabilities (auth, validation, testing)

## When to use me

Use this when the user asks to analyze, scout, or survey a project — or when you need to understand what a project is built with before making changes.

## Instructions

Call `altaria_analyze_project` to scan the project, then present the results as a structured report. Write the full report to `Altaria/Altaria-Scout.md` in the project root.
